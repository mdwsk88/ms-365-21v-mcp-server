# v0.1.1 · 依赖更新与发布元数据

日常维护版本：合并 14 个 Dependabot 依赖更新，补齐官方 MCP Registry 发布所需的元数据。此版本无功能变化，升级可直接替换镜像或源码。

## 依赖更新

- `actions/setup-node` 4 → 7、`actions/checkout` 4 → 7
- `docker/build-push-action` 6 → 7、`docker/setup-qemu-action` 3 → 4
- `@azure/msal-node` 5.3.1 → 6.0.0（仅使用 `ConfidentialClientApplication` / OBO 流程，未涉及 v6 移除的 API，已通过类型检查）
- `@modelcontextprotocol/sdk` 1.30.0 → 1.31.0、`hono` 4.13.1 → 4.13.7、`tsx` 4.22.4 → 4.23.13、`jose` 6.2.3 → 6.2.10、`@types/node` 26.0.1 → 26.6.4、`ip-address` 10.4.0 → 10.7.2、`proxy-addr` 2.0.7 → 2.0.8、`fast-uri` 3.1.7 → 3.1.8
- 暂缓：TypeScript 7（`typescript@7.0.2`，下个版本再评估）

## 仓库维护

- 新增 Dependabot 自动合并工作流：小版本/补丁升级在 CI 通过后自动 squash 合并，大版本仍需人工评审。
- Dependabot 配置改为按组聚合小版本/补丁更新，减少 PR 数量。
- 修复一个偶发的 Graph 超时测试 flake（5ms 定时器放宽到 50ms）。

## 发布元数据

- 新增仓库根目录 `server.json`（官方 MCP Registry 清单，已通过 `mcp-publisher validate` 校验）。
- Dockerfile 增加 `io.modelcontextprotocol.server.name` 归属 label，供 Registry 校验镜像归属。

## 安装

- 源码：下载本页 Source code，或克隆仓库并切换到 `v0.1.1`。按 [快速上手](https://github.com/mdwsk88/ms-365-21v-mcp-server/blob/v0.1.1/docs/QUICKSTART.md) 配置 Entra 和 `.env`。
- Docker：`docker pull ghcr.io/mdwsk88/ms-365-21v-mcp-server:v0.1.1`，支持 Linux amd64 / arm64。按 [镜像部署说明](https://github.com/mdwsk88/ms-365-21v-mcp-server/blob/v0.1.1/docs/CONTAINER.md) 启动。
- 附件包括 Compose 配置、`env.example`、镜像 digest 和 `SHA256SUMS`。镜像不包含租户凭据或用户令牌；未发布 npm 安装包。

## 升级与验证

已有部署保留原 `.env` 和状态目录，先备份并运行 `npm run doctor`。使用版本标签或 digest 固定镜像；回退到原镜像时继续挂载原状态卷。

发布流程执行完整自动化测试、公开发布检查、生产依赖审计及容器健康/OAuth 401/元数据/非 root 状态目录与重启持久化检查。

本次发布验证不包含真实租户 SSO、管理员同意、设备合规策略或 Graph 数据调用。上线后仍应完成 `auth_status` 和 `graph_get_me` 实测。
