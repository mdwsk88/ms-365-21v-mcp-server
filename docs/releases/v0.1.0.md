# v0.1.0 · 首个版本发布

面向世纪互联 Microsoft 365 的 MCP 服务。此版本包含 2026-09-05 合并的配置向导、诊断和依赖安全修复。

## 主要能力

- Streamable HTTP + OAuth bridge，以登录用户的身份调用 Microsoft Graph 中国区。
- 邮件、日历、OneDrive、SharePoint、Teams、联系人、组织用户、搜索与智能聚合工具；实际可见工具取决于模块、Graph 权限和 App Roles。
- 按用户控制工具权限，支持直接暴露、动态发现和混合模式。
- 写操作确认、预览、脱敏审计，以及 Graph 请求重试与超时处理。

## 最近优化

- `npm run setup` 生成最小配置，从读取个人资料开始；保留认证和 App Roles，不覆盖已有 `.env`。
- `npm run doctor` 离线检查常见配置问题，支持 JSON 输出，不输出配置值。
- 中文快速上手、英文概览和独立部署文档；HTTP 启动与构建命令兼容 Windows。
- 修复示例 `MCP_RESOURCE_URL` 覆盖真实服务地址的问题；现有 `.env` 需自行检查。
- 已合入 `fast-uri` 3.1.7、`qs` 6.16.0 两项依赖安全更新。

## 安装

- 源码：下载本页 Source code，或克隆仓库并切换到 `v0.1.0`。按 [快速上手](https://github.com/mdwsk88/ms-365-21v-mcp-server/blob/v0.1.0/docs/QUICKSTART.md) 配置 Entra 和 `.env`。
- Docker：`docker pull ghcr.io/mdwsk88/ms-365-21v-mcp-server:v0.1.0`，支持 Linux amd64 / arm64。按 [镜像部署说明](https://github.com/mdwsk88/ms-365-21v-mcp-server/blob/v0.1.0/docs/CONTAINER.md) 启动。
- 附件包括 Compose 配置、`env.example`、镜像 digest 和 `SHA256SUMS`。镜像不包含租户凭据或用户令牌；未发布 npm 安装包。

## 升级与验证

已有部署保留原 `.env` 和状态目录，先备份并运行 `npm run doctor`。使用版本标签或 digest 固定镜像；回退到原镜像时继续挂载原状态卷。首次从源码部署迁移到镜像时，需另行迁移原 `.tokens`，新建空卷不会继承原登录状态。

发布流程执行完整自动化测试、公开发布检查、生产依赖审计及容器健康/OAuth 401/元数据/非 root 状态目录与重启持久化检查。独立配置工具另有 Ubuntu/Windows × Node 22/24 测试矩阵。

本次发布验证不包含真实租户 SSO、管理员同意、设备合规策略或 Graph 数据调用。此前记录的 WorkBuddy、Qoder Work、Codex、Dify 兼容性不代表重新验证了所有客户端最新版本。上线后仍应完成 `auth_status` 和 `graph_get_me` 实测。
