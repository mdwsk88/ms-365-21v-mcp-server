# v0.2.0 · 工具精简与高频场景

客户端默认只看到读 Teams 聊天、邮件、日历和文档的高频只读工具；其余能力通过发现工具按需调用。管理员账号看到的工具从 126 个减到 13 个，工具清单从约 100 KB 减到约 15 KB。同时增加了 Host 头校验，服务在同机反向代理后可以只监听 `127.0.0.1`。

## 不兼容变更（升级前必读）

- 默认 `MCP_TOOL_EXPOSURE_MODE` 改为 `hybrid`。未设置 `MCP_DIRECT_TOOLS` 时，直接列出的业务工具是：
  - Teams：`teams_list_chats`、`teams_list_chat_messages`
  - 邮件：`mail_list_messages`、`mail_search_messages`、`mail_get_message`
  - 日历：`calendar_list_view`
  - 文档：`files_search`、`files_get_download_url`

  另外提供 `auth_status`、`confirm_execute` 和三个发现工具。
- 没有直接列出的工具不能再按名字调用，要通过 `gateway_search_tools` → `gateway_execute_tool` 执行，权限、写操作确认和审计不变。按名字调用其他工具的客户端或技能需要调整，或把工具加进 `MCP_DIRECT_TOOLS`。设置 `MCP_TOOL_EXPOSURE_MODE=direct` 可恢复旧行为。
- 上面这些场景工具改为返回精简字段，不再返回原始 Graph 数据。解析原始字段的客户端需要适配，例如邮件时间字段是 `receivedAt`，聊天消息是 `at`、`from`、`text`。
- `mail_list_folder_messages` 合并进 `mail_list_messages`，用 `folder` 参数选择文件夹。

## 新增与改进

- **Teams**：聊天列表按最近消息排序，带成员名和最后一条消息，可以按“某时间之后有新消息”、人名或群名查找。读消息返回纯文本，支持时间段和翻页，标出 @我 和分享的文件。
- **邮件**：按文件夹、时间段、标旗、未读、重要性、发件人筛选；读正文默认返回纯文本，可以只看本封新写的内容、分段读取，并附附件清单。
- **日历**：`calendar_list_view` 返回精简的会议信息，不带时区的时间按中国标准时间处理。
- **文档**：`files_search` 一次搜索 OneDrive 和 SharePoint；`files_get_download_url` 接收分享链接或文件 ID，返回短时有效的下载地址，由客户端自行下载和解析，可选先转换为 PDF，纯文本小文件直接附带内容。
- **发现工具**：中英文同义词与 BM25 排序；搜索结果附带排名靠前工具的参数说明，多数情况下“搜索 → 执行”两步完成；参数错误时返回正确格式。
- 所有工具输出改为紧凑 JSON，去掉 Graph 元数据和空值。
- `/healthz` 返回服务版本 `version`。

## 安全加固

- **Host 头校验**：服务监听 `127.0.0.1` 时，只接受 `localhost`、`127.0.0.1`、`[::1]` 和已配置的公网域名，其余 Host 返回 `403`。以前监听 `127.0.0.1` 时只接受本机名，同机 Nginx 转发公网域名会被拒绝，部署只能改用 `0.0.0.0`；现在可以只监听本机。新增 `MCP_ALLOWED_HOSTS` 用于补充其他域名，也可以为 `0.0.0.0` 开启校验。
- **角色边界不变**：文档类新工具需要 `mcp.drive`，访问 SharePoint 文件还需要 `mcp.sharepoint`；没有 `mcp.sharepoint` 时只返回 OneDrive 结果。
- 服务端说明提醒客户端：邮件、聊天和文件中的文字是不可信数据，下载地址不要转发给他人。

## Entra 配置

无需修改。本版本没有新增 App Role、Graph 委托权限或回调地址，新工具使用的权限与原有工具相同。

## 安装

- 源码：下载本页 Source code，或克隆仓库并切换到 `v0.2.0`。按 [快速上手](https://github.com/mdwsk88/ms-365-21v-mcp-server/blob/v0.2.0/docs/QUICKSTART.md) 配置 Entra 和 `.env`。
- Docker：`docker pull ghcr.io/mdwsk88/ms-365-21v-mcp-server:v0.2.0`，支持 Linux amd64 / arm64。按 [镜像部署说明](https://github.com/mdwsk88/ms-365-21v-mcp-server/blob/v0.2.0/docs/CONTAINER.md) 启动。
- 附件包括 Compose 配置、`env.example`、镜像 digest 和 `SHA256SUMS`。镜像不包含租户凭据或用户令牌；未发布 npm 安装包。

## 升级与验证

已有部署保留原 `.env` 和状态目录，先备份并运行 `npm run doctor`。同机 Nginx 反向代理的部署，升级后可以把 `MCP_HTTP_HOST` 改为 `127.0.0.1`。客户端重新连接后才会刷新工具列表。

发布流程执行完整自动化测试（102 项，含一次真实启动服务的 Host 头校验）、公开发布检查、生产依赖审计及容器健康检查。在 21V 租户中只读验证过聊天、聊天消息和邮件的查询写法。

尚未用真实登录验证：文档搜索中的 Microsoft Search、分享链接解析和转 PDF。上线后仍应完成 `auth_status`、`graph_get_me` 和一次文档查询实测。
